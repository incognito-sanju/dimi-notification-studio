# DIMI Notification Studio

these are demo designs for the full screen notification you need to design for me identical type but fully professional standard and modern -- desing fresh with these ideas -DIMI — Technical Brief for UI Designer

1. App overview: DIMI (Digital Interface for Monitoring and Improvement) is an offline-first Android productivity app built with Flutter and Dart.

2. Tech stack:

UI: Flutter + Dart

State management: Riverpod

Local database: Drift (SQLite)

Backend and authentication: Supabase + Google Sign-In

Navigation: go_router

3. Core features: Home dashboard, To-Dos, Planner, Finance, Reminders, and YouTube Playlist Tracker.

4. Design system:

Primary color: #F5A623

Light theme: warm cream background, white cards, dark text.

Style: minimal, premium, Apple-inspired.

Rounded cards, subtle shadows, clean typography, consistent icons.

5. Design three full-screen notifications:

Planner: Calendar illustration, event details, duration, "Slide to start session."

YouTube: Video/play illustration, playlist thumbnail, channel, progress, "Slide to continue learning."

Reminder: Bell illustration, reminder title, date/time, "Slide to mark as done."

6. Common actions: "Snooze 5 min" and "Not now."

7. Requirements: Use dynamic app data, responsive layouts, reusable components, accessible sliders, and consistent DIMI branding. Avoid excessive glow, clutter, unnecessary subtitles, and the regular bottom navigation.

Reference: Follow the existing DIMI Home, Planner, To-Dos, Finance, Reminders, and Playlist Tracker screens. Design the notifications as one consistent system with different illustrations and actions.
